# Assignment 4: MIPS Game

### 1. Tic Tac Toe
* **Design Note**: Tic Tac Toe is a game played on a 3x3 board with an X and O player taking turns to get 3 in a row. X player goes first. To implement, `Main` calls `DrawBoard` to paint the white grid and its black lines. Then `GameLoop` waits for a key with `ReadKey` and turns 1–9 into a square index 0–8. The board byte array (0 = empty, 1 = X, 2 = O) rejects squares that are already taken, so each square can only be marked once. `DrawMark` divides the index by 3 to find the row and column, then plots a 5×5 X or O with `SetPixel`. `CheckWin` tests the current player against the 8 lines in `win_lines`, 9 moves with no winner is a draw, and `xori` switches players. 
* **How to Run**: Open `1. TicTacToe.asm` in MARS and open Tools → Bitmap Display. Set Unit Width/Height 8px, Display Width/Height 256px and base address 0x10010000 (static data), then click Connect to MIPS. Open Tools → Keyboard and Display MMIO Simulator and click Connect to MIPS. Assemble (F3), run (F5), and type 1–9 in the KEYBOARD box (1 = top-left, 9 = bottom-right). Prompts and the result appear in the Run I/O console.

### 2. BlackJack
* **Design Note**: BlackJack is a card game against the dealer where you have to accumulate suits of cards to as closely reach 21. To implement, `DealCard` picks a random card from the shared 52-card `deck` and moves the last card into its spot, so no card is dealt twice. `HandValue` counts J/Q/K as 10 and an ace as 11 if that doesn't bust, otherwise 1. In `PlayerTurn`, Y calls `HitPlayer` and N stands, and the turn ends on its own at 21 or more. `DealerLoo`p then hits on 0–13, stands on 19+ and flips a coin on 14–18, and `CompareHands` picks the winner. Every character is a bitmap string like `".#./#.#/###/#.#/#.#"` that `GetGlyph` looks up and `DrawBitmap` draws.
* **How to Run**: Open 2. `BlackJack.asm` and set the Bitmap Display to Unit Width/Height 4px, Display Width/Height 256px and base address 0x10010000 (static data). Connect the Bitmap Display and the Keyboard MMIO Simulator to MIPS, then assemble and run. Type Y to hit or N to stand in the KEYBOARD box. After you stand, the dealer plays and the result appears in the middle of the screen. 

### 3. Custom Game: Snake
* **Design Note**: Snake is a 2D real-time game where you move a snake in cardinal directions to eat apples, in which the snake grows longer. Goal is to play for as long as possible, avoiding collision with tail and wall. To implement, for each cell the snake is on, the 16×16 `grid` stores 1 + the direction to the next segment, so the tail can follow the body without a list of positions. Each tick, `GameLoop` calls `PollKe`y without waiting and `KeyDirection` turns W/A/S/D into a direction, ignoring a turn straight back. `StepCell` returns -1 when the head would leave the board, which is a wall loss. The tail moves before the head unless the snake is eating, so the head may enter the tail's old cell, but any other occupied cell loses. Eating grows the snake, reaching length 256 wins, and `RandomEmptyCell` places each new apple, while `DrawBitmap` rotates the letter-coded sprites and `ShowModal` shows the result.
* **How to Run**: Open `3. Snake.asm` and set the Bitmap Display to Unit Width/Height 2px, Display Width/Height 512px and base address 0x10010000 (static data). Connect the Bitmap Display and the Keyboard MMIO Simulator, set the Run Speed slider to max, then assemble and run. Press W/A/S/D in the KEYBOARD box; the first key starts the game, and `TICK_MS` sets the speed. To watch a bot win, run `3. SnakeAutoplay.asm` with the same display settings. It needs no keyboard and follows `bot_path`, a loop through every cell.
